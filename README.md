# ☕ Coffee Shop Menu

A modern and interactive **Coffee Shop Menu** web application built using **Angular**. This project allows users to browse a coffee menu, search for their favorite coffee, view prices and availability, and place an order through a simple and attractive user interface.

## 📂 GitHub Repository

---

## ✨ Features

* ☕ Displays a beautiful coffee menu.
* 🔍 Real-time coffee search using Angular.
* 💰 Displays the price of each coffee.
* ⭐ Highlights **Bestseller** coffees.
* 🔥 Highlights **Hot Selling** coffees.
* 💚 Displays available coffees.
* 🛒 "Order Now" button with confirmation message.
* ❌ Friendly coffee-themed message when no matching coffee is found.
* 🎨 Clean and responsive coffee-themed user interface.

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/manu-96681/coffee-shop-menu.git
```

2. Open the project:

```bash
cd coffee-shop-menu
```

3. Install dependencies:

```bash
npm install
```

4. Run the application:

```bash
ng serve
```

5. Open your browser and visit:

```text
http://localhost:4200/
```
